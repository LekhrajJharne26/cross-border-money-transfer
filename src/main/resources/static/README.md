# CrossBorder Money Transfer UI

Frontend-only responsive prototype for the CrossBorder Money Transfer application. It uses plain HTML, CSS, and JavaScript and does not modify or call backend code.

## Run

Open `index.html` in a modern browser. For live reload, open the `cross-border-money-transfer-ui` folder with a local static server such as VS Code Live Server.

## Included screens

- Login and registration
- Dashboard with summary cards, recent transactions, and quick actions
- Beneficiary list with add, edit, and delete interactions
- Country and banking-partner catalogues
- Send Money form with country-driven partner options
- Transaction history with search and status filtering
- Profile and responsive navigation

## Storage

The prototype stores demo session, beneficiary, and transaction information only in browser `localStorage`. It does not send data to the Spring Boot backend.
